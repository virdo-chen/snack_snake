# 文字版贪吃蛇
很遗憾，最初编写这个东西的时候使用的是*VScode*，运行挂的*minGW g++*，它似乎支持一些目前没有被全面接受的c++标准
（例如：创建一个长度为编译时非常量的数组）。这导致了一个**小**问题：它没法被VS的默认运行环境接受。

当然，这个实际上只影响了工程显示部分的一点点内容，因而修改也很、容易，
### 但我发觉这个小东西已经远远背离了我的初衷。
起初编写这个东西，是为了给一个*弱爆了*的单片机（对，就是你，*arduino uno*）设计一个不至于把它那可怜的内存撑爆的
贪吃蛇小游戏。最早是在电脑上写了一个文字版的原型，本来想着可以很容易的移植过去，结果经过计算发现我还是太高看这玩意儿
的内存容量了。不得已，又一次专门为它设计了*special minimized*版本（存于minimized分支），这个移植没我起初想的那
么丝滑，而且为了压缩内存，我真是拼尽了全力。

现在我的目的达到了。arduino上的小游戏玩两下就没意思了，
### 继续执着于这个项目已然毫无意义。
不论从哪个方面来看，我都不应该再执着于它了。现在留下它为数不多的原因之一，是希望收拾烂摊子，把数组全换成vector，顺带
学习一下vector的用法。
###### 然后就让它烂在这里吧~
